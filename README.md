# 智慧员工运营系统 (HR Management System)

## 项目概述

该系统为现代化企业人力资源管理系统，基于B/S三层结构的Web应用，采用浏览器-服务器-数据库架构模式。用户通过浏览器向服务器发送请求，服务器接收并分析客户端请求后，将所需页面和数据响应到客户端。该模式统一了客户端操作界面，将系统功能实现的核心部分集中到服务器端，简化了系统的开发、维护和使用。

系统服务器端采用Django轻量级Web框架，该框架开源免费、执行效率高，适用于中小型企业级应用，支持RESTful API、用户认证、权限控制等现代Web开发常用功能。数据库采用MySQL关系型数据库，具有开源免费、使用简单、性能优良的特点。前端采用Vue3+TypeScript+Element Plus技术栈，实现了现代化的响应式用户界面。整体架构采用MVC设计模式，强制将开发内容分为模型(Model)、视图(View)、控制器(Controller)三大模块，便于分模块开发并减少模块间的耦合度。

## 系统架构

该系统分为三个层次：

**第一层：表现层（用户层）**  
存在于客户端浏览器，用户通过Web界面选择不同的角色类型进行登录（管理员、部门经理或普通员工），登录成功后系统提供相应的操作界面。主要功能模块包括考勤打卡、请假申请、薪资查询、绩效管理等。不同角色具有不同的权限：员工用户界面主要提供考勤打卡、请假申请、个人信息查看等功能；经理用户界面包含员工管理、请假审批、考勤统计等功能；管理员界面则提供完整的系统管理功能。该层采用Element Plus组件库实现友好的用户交互体验，支持表单提交、数据展示、状态反馈等功能。

**第二层：业务层（应用层）**  
存在于后台服务器中，负责客户端与数据库之间的交互处理。通过Django REST Framework提供RESTful API接口，接收客户端发送的各类请求（如考勤记录、请假申请、用户认证等），对请求参数进行验证和业务逻辑处理后，与数据库进行交互操作，最终将处理结果以JSON格式响应给客户端。该层实现了用户认证、权限控制、数据验证、业务规则等核心功能。

**第三层：数据层（持久层）**  
后台系统通过Django ORM与MySQL数据库进行交互，将业务层处理后的数据持久化存储在数据库中。当客户端需要数据时，数据层通过执行SQL命令对相应数据表进行查询、插入、更新、删除等操作，并将结果返回给业务层。数据库设计包含用户表、部门表、考勤表、请假表、薪资表、绩效表等核心业务表。

## 系统特色

- **多角色权限管理**：支持管理员、部门经理、普通员工三种角色，实现精细化权限控制
- **现代化技术栈**：前端Vue3+TypeScript，后端Django+DRF，确保系统的先进性和可维护性  
- **响应式设计**：基于Element Plus的现代化UI界面，支持多终端访问
- **完整业务流程**：涵盖考勤管理、请假流程、薪资核算、绩效评估等完整HR业务链
- **智能化功能**：支持人脸识别打卡、地理位置验证等智能化考勤方式
- **数据可视化**：提供图表统计和报表分析功能，支持管理决策

## 技术栈

- **前端**：Vue 3 + TypeScript + Element Plus + Vite
- **后端**：Django 5.1.5 + Django REST Framework + JWT认证
- **数据库**：MySQL 8.0+
- **其他**：ECharts图表、face-api.js人脸识别、Pinia状态管理
